## 📝简介

QRcode Scaner（二维码识别器）是一款功能全面的二维码解析工具，支持识别市面上几乎所有类型的二维码，包括百度网盘、夸克网盘等国内网盘的二维码。


## ✨ 主要功能

- **右键菜单识别**：在任意网页图片上右键，选择"识别二维码"即可快速解析；其下还提供「自动 / 本地识别 / 在线识别」子菜单，可指定本次识别所用模式
- **识别模式切换**：支持「自动 / 本地识别 / 在线识别」三种识别模式，可按需灵活切换识别策略
- **粘贴剪贴板图片**：直接从剪贴板读取图片进行识别
- **上传本地图片**：支持 JPG、PNG、GIF、WebP 等常见图片格式
- **框选网页区域**：拖拽鼠标选择网页中的二维码区域，精准识别
- **多结果展示**：当图片包含多个二维码时，分别列出每个识别结果
- **一键复制**：点击复制按钮快速复制识别结果
- **快捷打开链接**：识别结果为网址时，可直接打开链接


## 🔧 使用说明

- **右键识别**：在网页图片上右键 → 选择「识别二维码」 → 选择所需模式
- **切换识别模式**：点击扩展图标 → 在弹窗标题下方的「识别模式」下拉框中选择「自动 / 本地识别 / 在线识别」
- **剪贴板识别**：复制二维码图片 → 点击扩展图标 → 点击「粘贴自剪贴板」
- **上传图片识别**：点击扩展图标 → 点击「上传本地图片」 → 选择二维码图片
- **框选识别**：点击扩展图标 → 点击「框选网页区域」 → 拖拽鼠标选择二维码区域

## 🔒 隐私说明

本扩展高度重视你的隐私，二维码识别的全过程遵循以下原则：

- **自动模式（默认）**：优先本地解码，仅当本地识别失败时，才将图片发送至 **草料二维码 API** 进行识别
- **本地识别模式**：内置 zxing-wasm，默认在**你的设备本地离线解析**二维码，图片**绝不会**上传到任何服务器，完全离线
- **在线识别模式**：图片会始终发送至 **草料二维码 API** 进行识别
- **结果仅存本地**：识别结果仅保存在浏览器本地存储，**5 分钟后自动清除**，不会上传或长期留存
- **完整政策**：详细隐私政策请查阅 https://ononameo.github.io/QRcode-Scaner/
