一、概述

《QRcode Scaner（二维码识别器）》是一款用于在本地或按需联网识别二维码内容的浏览器扩展。

本隐私策略依据 Microsoft Edge 扩展商店的合规要求编写，清楚说明本扩展所请求的权限及其用途、我们如何处理您的数据，以及是否及如何与第三方共享数据。如您对本策略有任何疑问，可通过文末联系方式与我们沟通。

二、我们处理的数据

本扩展仅在您主动触发识别时处理以下数据，且不会收集任何与识别无关的个人信息（如姓名、账号、设备标识符、位置、浏览历史等）：

  • 您主动上传的二维码图片（通过"上传本地图片"选择）；
  • 您剪贴板中的图片（通过"粘贴自剪贴板"读取）；
  • 您在网页上框选的截图区域（通过"框选网页区域"截取）；
  • 网页图片地址（URL）（通过右键菜单识别时，用于获取该图片的资源）；
  • 识别结果文本（由上述图片解码得到的内容）。

以上数据均为"用户提供的图片内容"。本扩展不读取、不存储您的浏览历史、Cookie、密码或其他网页表单数据。

三、权限说明

为提供上述识别功能，本扩展在 Microsoft Edge 中申请以下权限。每一项权限均严格限定于实现对应功能，我们不会将其用于声明用途之外的任何目的：

权限用途说明
contextMenus在网页图片上右键时显示"识别二维码"菜单及其识别模式子菜单，便于您快速发起识别。
activeTab当您使用"框选网页区域"功能时，临时获取当前活动标签页的访问能力，用于截取您所选中的二维码区域。仅在您主动框选时生效，不会持续访问或监听页面。
scripting配合 activeTab，在您框选时于当前活动标签页中注入必要的脚本以捕获选区坐标并完成截图，是框选功能的技术前提。
clipboardWrite将识别结果复制到系统剪贴板，便于您粘贴使用。
clipboardRead读取剪贴板中的图片，以支持"粘贴自剪贴板"识别。仅在您点击该按钮时读取，不会在后台监视剪贴板。
offscreen创建无界面的离屏文档（Offscreen Document），在 DOM / Canvas 环境中裁剪图片并调用内置 zxing-wasm 引擎进行本地离线解码。所有解码均在您本机完成。
storage使用浏览器本地存储（chrome.storage.local）临时保存识别状态与结果，便于弹窗展示与取消识别。数据仅存于本地，5 分钟后自动清除。
host_permissions（<all_urls>）为支持对任意网页上的图片进行右键识别与框选，需要访问相应页面的图片资源（读取图片 URL 并获取其数据用于解码）。仅在您发起识别时访问目标页面资源，不用于其他用途。

四、数据的使用方式

我们处理上述数据的唯一目的是识别二维码中的文本内容，绝不用于其他用途。根据您所选的识别模式，解码过程分为以下两种方式：

  • 本地识别（离线）：默认采用的方式。图片在本机通过内置的 zxing-wasm 引擎完成识别，全过程无需联网，图片内容不会离开您的设备。
  • 在线识别（联网）：当您主动选择"在线识别"模式，或"自动"模式下本地解码失败时，图片会被发送至草料二维码 API 完成识别。在线识别仅传输待识别的图片本身，不含任何其他信息（具体见第五节"第三方数据共享"）。

无论采用哪种解码方式，识别所得的文本结果均仅在本扩展弹窗中向您展示，并临时保存在浏览器本地存储中；我们不会将这些图片或识别结果用于任何分析、用户画像、广告投放或其他商业化用途。

五、第三方数据共享

本扩展不会出售、出租、交易或以其他方式转让您的数据。除下述唯一必要的第三方服务外，我们不向任何第三方共享数据：

唯一第三方：草料二维码 API（https://api.2dcode.biz/v1/read-qr-code）

当本地离线解码不可用或您主动选择联网时，图片会被发送至草料二维码 API 以完成识别。具体触发情形如下：

  • 自动模式（默认）：仅当本地解码失败时，作为兜底方案将图片发送至草料二维码 API；若本地识别成功，图片不上传。
  • 在线识别模式：您主动选择始终使用联网识别，图片会持续发送至草料二维码 API。
  • 本地识别模式：图片绝不会上传至任何服务器，完全离线。

发送至草料二维码 API 的内容仅限于待识别的图片本身，不含任何其他个人信息。关于草料方如何处理该数据，请参见其解码 API 说明。

六、数据存储与保留

  • 识别状态与结果使用浏览器本地存储（chrome.storage.local）保存，不会上传到我们的服务器；
  • 本地存储的保留期限为 5 分钟，超时后自动清除；
  • 您可随时点击弹窗中的"返回"按钮手动清除当前识别结果；
  • 待识别的图片数据在解码完成后即被释放，不会在本地持久化保存。

七、数据安全

  • 本扩展不涉及用户账号体系，不设置 Cookie，不进行任何行为追踪或埋点统计；
  • 本地解码全程在您设备的离屏文档中完成，图片不出本机；
  • 仅在与草料二维码 API 通信时采用必要的网络传输，且传输内容仅限于待识别图片。

八、您的权利与控制

  • 您可以随时在弹窗中取消正在进行的识别；
  • 您可以点击"返回"按钮清除历史识别结果；
  • 您可以自主决定是否打开识别出的链接；
  • 您可以通过切换到"本地识别模式"确保图片绝不离开本机；
  • 您有权就本隐私策略及数据处理方式向我们提出询问或异议。

我们可能会不时更新本隐私策略。如发生涉及数据收集或使用方式的重大变更，我们将在扩展更新说明中予以提示。建议您定期查阅本页面以了解最新内容。
